# Brain Tumor Classification and Segmentation

This repository combines two related projects for brain tumor analysis:

- Classification: CNN-based classification of MRI images into tumor-related classes
- Segmentation: segmentation of tumor regions from medical imaging data

## Repository Structure

- `classification/` — classification notebooks, scripts, plots, and evaluation results
- `segmentation/` — segmentation notebooks, scripts, and output visualizations

## Notes

- Large trained model weights such as `.pth`, `.pt`, `.ckpt`, `.bin`, `.onnx`, and `.h5` files are not included in this repository.
- This project is intended for academic and research purposes.
- Additional pretrained weights can be added locally if needed for reproduction or inference.

## Purpose

This repository provides a complete combined view of the brain tumor workflow, covering both classification and segmentation tasks.
